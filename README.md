# 실시간 출결 및 현황판 (Count & Status Sync)

스마트폰 모바일 환경에서 관리자(최대 2인)와 팀원들이 실시간으로 출결, 부스 운영 시간대, 전우조(조별) 현황 및 자리비움(화장실, 흡연, 기타) 시간을 상호 동기화하며 추적하는 모바일 웹/PWA 애플리케이션입니다.

**배포 주소**: https://count-likelion.vercel.app/

---

## ✨ 핵심 기능 및 업데이트 사항

1. **산뜻하고 가벼운 모던 클린 UI**
   - 밝고 쾌적한 화이트 & 소프트 슬레이트 디자인과 직관적인 48px+ 터치 인터페이스
2. **역할 분기 접속 (`/join`)**
   - **관리자 모드**: 룸 코드 + PIN 번호로 관리자 대시보드 입장
   - **사용자 모드**: 룸 코드 입력 후 인원 목록 중 **본인 이름 선택**으로 간편 입장
   - **출석 연동**: 관리자가 사전 출석했거나, 사용자가 입장 시 `[출석 체크 및 내 화면 입장]`으로 직접 체크 가능
3. **인원 정보 확장 및 관리자 전용 관리**
   - **전우조 (`group`)**: 조별 모아보기 탭을 통해 전우조끼리 그룹핑하여 현황 확인
   - **부스 운영 시간대 (`shiftTime`)**: 시간대별 정렬 탭을 통해 교대 시간대별 인원 확인
   - **전화번호 (`phone`)**: 관리자 대시보드에서 `tel:` 원터치 전화 걸기 지원 (일반 사용자에게는 비노출)
4. **원터치 자리비움 타이머 (화장실 / 흡연 / 기타)**
   - 나갈 때 버튼을 누르면 실시간 초/분 단위 타이머가 작동하고, 복귀 시 다시 누르면 종료
   - '기타' 사유 선택 시 빠른 칩(통화, 미팅, 편의점 등) 또는 직접 입력 지원
   - 사용자 본인 화면과 관리자 2명의 화면에 **실시간 1초 이내 동기화**
5. **상세 타임로그 히스토리 & 사용자 패널 최적화**
   - 사용자 화면의 불필요한 메인 박스를 제거하고 상단 `[내 기록]` 드로어를 통해 깔끔하게 확인
   - 언제 나가서 언제 복귀했는지 타임스탬프 이력 보관
6. **듀얼 실시간 스토리지 지원**
   - **Firebase Realtime DB**: 클라우드 원격 멀티 디바이스 실시간 동기화 (배포 환경변수 정제·읽기 정규화로 프로덕션 안정화됨)
   - **Local BroadcastChannel**: 별도 서버 설정 없이 로컬 멀티 탭/브라우저 실시간 동기화
7. **PWA 홈 화면 설치**
   - 모바일 브라우저에서 "홈 화면에 추가"로 독립 실행형 앱처럼 설치 가능 (standalone, 아이콘 3종)
8. **모바일 무음 알림**
   - 자리비움 임계 시간 초과 시 서비스워커 경로로 무음(silent) 시스템 알림 발송. 소리 경고음은 없음
9. **동기화 실패 노출 & 전역 오류 경계**
   - 클라우드 저장·구독 실패를 화면에 숨기지 않고 상태코드별 한국어 안내로 표시
   - 렌더 예외 발생 시 검은 화면 대신 오류 메시지 + 새로고침 버튼(`ErrorBoundary`) 표시
10. **기기 기준 룸 목록**
    - 룸 목록 모달은 서버 전체 열거 대신 이 기기가 최근 방문한 룸(최대 10개)만 보여줌. 삭제 버튼은 데이터를 보존하는 "이 기기 목록에서 빼기"로 동작

## 🚀 빠른 시작

### 1. 의존성 설치
```bash
npm install
```

### 2. 환경변수 설정
프로젝트 루트에 `.env.local`을 만들고 `.env.example`을 참고해 Firebase 프로젝트의 `VITE_FIREBASE_*` 7개 값을 채웁니다. 미설정 시 Local BroadcastChannel 모드로 자동 폴백합니다.

> **Vercel 등 배포 대시보드에 값을 입력할 때는 따옴표(`"`, `'`)를 붙이지 마세요.** 따옴표를 포함해 저장하면 그대로 번들에 인라인되어 `databaseURL`이 깨지고 실시간 동기화가 실패합니다(코드에도 `sanitizeConfigValue()`로 방어 로직이 있지만, 애초에 따옴표 없이 입력하는 것이 원칙입니다).

### 3. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173/` 접속

### 4. 테스트 실행
```bash
npx vitest run
```

### 5. 프로덕션 빌드
```bash
npm run build
```

> 위 명령은 docs/CodingRules.md "검증된 명령어" 절에 기록된 원문입니다. 그 외 스크립트(`npm run preview` 등)는 package.json에는 있으나 검증 기록은 없습니다.

## 📱 PWA 설치 방법

1. 핸드폰 브라우저(Chrome/Safari)로 배포 주소에 접속합니다.
2. 브라우저 메뉴에서 "홈 화면에 추가"를 선택합니다.
3. 관리자 화면의 "알림 켜기" 버튼으로 알림 권한을 허용하면 자리비움 초과 시 무음 알림을 받을 수 있습니다.

## 🔒 Firebase 보안 규칙

`firebase.rules.json`을 Firebase 콘솔 → Realtime Database → 규칙 탭에 붙여넣어 게시합니다. **현재 이 리포의 규칙은 게시 완료 상태**이며, 무인증 상태의 루트 읽기·전체 룸 열거·루트 임의 쓰기·`/rooms` 통째 덮어쓰기·필수 필드 없는 룸 생성·룸 삭제를 차단합니다.

**알려진 한계**: 인증이 없어 룸 코드를 아는 사람의 읽기·수정까지는 막지 못합니다. 부스를 실제 운영에 투입하기 전에는 익명 인증 전환이 필요합니다 (`docs/Tasks.md` T-14, 현재 보류 상태 — 테스트 기간에는 자유롭게 운영하기로 사용자가 선택함).

## 🗂️ 룸 관리 운영 방식

앱 화면(룸 목록 모달)에서는 **이 기기가 접속했던 룸 기록**만 보여줍니다(localStorage 기반, 서버 전체 열거 없음). 전체 룸 조회, 영구 삭제, 복구가 필요하면 **Firebase 콘솔 → Realtime Database → 데이터 탭**에서 직접 수행합니다. 앱의 삭제 버튼은 데이터를 지우지 않고 "이 기기 목록에서만" 제외합니다.
