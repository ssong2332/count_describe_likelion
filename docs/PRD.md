# PRD — 실시간 출결 및 자리비움 현황판 (Count & Status Sync)

> 소유자: planner | 상태: 승인 | 최종 수정: 2026-08-25
> 상태는 초안/승인 두 가지. 사용자 승인 완료됨 (AGENTS.md 파이프라인 규칙).
> 2026-08-25 사후 반영: 배포 후 긴급 대응(T-09~T-13)으로 실제 구현된 내용을 F-10~F-13, N-05~N-07로 추가하고 F-09를 갱신했다. 이 추가분은 사용자 승인 대상이며 planner가 상태를 임의로 바꾸지 않는다.

## 한 줄 정의

모바일 환경에서 현장 관리자(최대 2인)는 전체 인원의 출결 및 자리비움을 실시간 모니터링·관리하고, 일반 사용자는 본인 전용 화면에서 화장실·흡연·기타 상태를 직접 ON/OFF 토글할 수 있는 실시간 모바일 웹/PWA 애플리케이션.

## 배경 / 문제

- 관리자가 모든 사람의 화장실/흡연/기타 사유를 일일이 대신 눌러주기 어려운 상황이 발생함.
- 일반 사용자가 스마트폰으로 직접 자기 자리비움 상태(화장실, 흡연, 기타)를 원터치로 켜고 끌 수 있으면 관리자의 수고가 대폭 줄어들고 기록의 정확도가 향상됨.
- 관리자 화면과 사용자 화면의 역할을 분리하여, 사용자는 불필요한 전체 수정 권한 없이 본인 상태만 심플하게 제어하고, 관리자는 실시간 대시보드로 전체 현황을 한눈에 파악할 수 있는 체계가 필요함.

## 사용자

| 사용자 유형 | 핵심 니즈 |
|---|---|
| 현장 관리자 (최대 2인) | 룸 생성/PIN 관리, 전체 대시보드 확인, 인원 추가/수정/삭제, 출결 체크, 전체 자리비움 모니터링/수동 제어, 데이터 리셋 |
| 일반 사용자 (인원) | 룸 코드 입력 후 본인 이름 선택 → 본인의 화장실/흡연/기타 상태 원터치 토글 및 실시간 타이머/내 기록 확인 |

- 복잡한 회원가입 및 소셜 OAuth 로그인 (간편 룸코드/PIN 및 이름 선택 방식에 집중)

- 유료 푸시 알림(FCM 서버 푸시) 및 SMS 발송 — F-10은 앱이 열려 있을 때 브라우저/서비스워커가 직접 띄우는 로컬 알림이며 서버 푸시가 아니다.
- 익명 인증 기반 접근 제어 (Open Question 2 — 부스 실운영 전 재검토, 현재 범위 밖)

- 관리자가 출석 체크 및 자리비움 제어를 원격으로도 수행 가능함.
- 단위/컴포넌트 테스트 100% 통과 및 모바일 UI 터치 반응 오류 0건.
