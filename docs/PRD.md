# PRD — 실시간 출결 및 자리비움 현황판 (Count & Status Sync)

> 소유자: planner | 상태: 승인 | 최종 수정: 2026-08-24
> 상태는 초안/승인 두 가지. 사용자 승인 완료됨 (AGENTS.md 파이프라인 규칙).

## 한 줄 정의

모바일 환경에서 현장 관리자(최대 2인)는 전체 인원의 출결 및 자리비움을 실시간 모니터링·관리하고, 일반 사용자는 본인 전용 화면에서 화장실·흡연·기타 상태를 직접 ON/OFF 토글할 수 있는 실시간 모바일 웹/PWA 애플리케이션.

## 배경 / 문제

- 관리자가 모든 사람의 화장실/흡연/기타 사유를 일일이 대신 눌러주기 어려운 상황이 발생함.
- 일반 사용자가 스마트폰으로 직접 자기 자리비움 상태(화장실, 흡연, 기타)를 원터치로 켜고 끌 수 있으면 관리자의 수고가 대폭 줄어들고 기록의 정확도가 향상됨.
- 관리자 화면과 사용자 화면의 역할을 분리하여, 사용자는 불필요한 전체 수정 권한 없이 본인 상태만 심플하게 제어하고, 관리자는 실시간 대시보드로 전체 현황을 한눈에 파악할 수 있는 체계가 필요함.

## 사용자

| 사용자 유형 | 핵심 니즈 |
|---|---|
| 현장 관리자 (최대 2인) | 룸 생성/PIN 관리, 전체 대시보드 확인, 인원 추가/수정/삭제, 출결 체크, 전체 자리비움 모니터링/수동 제어, 데이터 리셋 |
| 일반 사용자 (인원) | 룸 코드 입력 후 본인 이름 선택 → 본인의 화장실/흡연/기타 상태 원터치 토글 및 실시간 타이머/내 기록 확인 |

## 요구사항

### 기능 요구사항

| ID | 요구사항 | 우선순위 (필수/권장/보류) | 승인 기준 (검증 가능한 조건 — Given-When-Then 권장) |
|---|---|---|---|
| F-01 | 룸 생성 및 모드별 접속 (관리자 PIN vs 사용자 이름 선택) | 필수 | Given 룸 코드가 주어졌을 때, When 관리자는 PIN으로 입장하고 일반 사용자는 등록된 인원 목록 중 본인 이름을 선택해 입장하면, Then 각각 관리자 대시보드와 사용자 전용 제어 화면으로 진입한다. |
| F-02 | 관리자: 인원 추가 / 수정 / 삭제 | 필수 | Given 관리자 모드로 접속한 상태에서, When 새 인원을 등록하거나 기존 인원을 삭제/수정하면, Then 실시간으로 룸 인원 목록 및 사용자 선택 화면에 즉시 동기화된다. |
| F-03 | 관리자: 출석 여부 2단계 토글 | 필수 | Given 관리자 대시보드에서, When 특정 인원의 출석/결석 토글 버튼을 누르면, Then 출석 상태가 전환되고 상단 대시보드 요약 카운터가 즉시 갱신된다. |
| F-04 | 자리비움 ON/OFF 토글 및 실시간 타이머 (사용자 직접 조작 & 관리자 조작) | 필수 | Given 인원이 출석 상태일 때, When 사용자(본인 화면) 또는 관리자(대시보드)가 '화장실'/'흡연' 버튼을 누르면, Then 상태가 활성화되고 실시간 경과 시간(초/분) 타이머가 작동하며 2인 관리자 및 본인 화면에 실시간 동기화된다. 다시 누르면 종료된다. |
| F-05 | 기타 사유 입력 모달 및 상태 토글 | 필수 | Given 인원이 출석 상태일 때, When '기타' 버튼을 누르면, Then 사유 입력 모달이 열리고 사유(예: 통화, 미팅 등)를 입력해 활성화하면 해당 사유 뱃지와 함께 타이머가 작동한다. |
| F-06 | 사용자: 본인 전용 제어 화면 | 필수 | Given 일반 사용자가 본인 이름으로 입장했을 때, When 화면을 보면, Then 본인의 현재 상태(출석 여부, 화장실/흡연/기타 버튼, 실시간 경과 타이머, 오늘 내 총 자리비움 시간 및 기록)만 깔끔하게 노출된다. |
| F-07 | 상세 타임로그(출입 히스토리) 기록 및 뷰어 | 필수 | Given 자리비움이 종료되었을 때, When 관리자 대시보드 또는 사용자 화면에서 '로그 보기'를 누르면, Then 당일 자리비움 유형, 사유, 출발 시간, 복귀 시간, 총 소요 시간 히스토리가 표시된다. |
| F-08 | 당일 데이터 수동 초기화 (Reset) | 필수 | Given 관리자 모드에서, When 관리자가 확인 팝업을 거쳐 '초기화'를 실행하면, Then 인원들의 출결 상태 및 당일 자리비움 로그가 초기 상태로 리셋된다. (사용자 모드에서는 불가) |
| F-09 | PWA (홈 화면 바로가기) 지원 | 권장 | Given 모바일 브라우저로 접속했을 때, When 홈 화면에 추가를 선택하면, Then 독립 실행형 앱(standalone) 형태로 설치되어 편리하게 실행된다. |

## 범위 제외 (이번에 하지 않는 것)

- 복잡한 회원가입 및 소셜 OAuth 로그인 (간편 룸코드/PIN 및 이름 선택 방식에 집중)
- 과거 일자별 캘린더 검색 및 월간 통계 (당일 실시간 현황 모니터링에 집중)
- 유료 푸시 알림 및 SMS 발송

## 성공 기준

- 일반 사용자가 본인 폰에서 '화장실' 버튼을 누르면 관리자 2명의 화면에 1초 이내에 타이머 작동 상태가 동기화됨.
- 관리자가 출석 체크 및 자리비움 제어를 원격으로도 수행 가능함.
- 단위/컴포넌트 테스트 100% 통과 및 모바일 UI 터치 반응 오류 0건.
