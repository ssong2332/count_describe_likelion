# CHANGELOG

모든 주요 변경 사항이 이 파일에 기록됩니다.

## [Unreleased] - 2026-08-24 (10대 UX/기능 고도화)

### 추가 / 개선 (Added & Improved)
1. **메인 화면 간소화**: 메인 접속 화면에서 '룸 목록 관리' 버튼을 제거하여 진입 경로 단일화.
2. **원클릭 빠른 입장**: 최근 접속 기록의 `[불러오기]` 버튼 클릭 시 폼 채우기 단계를 건너뛰고 해당 룸/역할로 즉시 대시보드 진입.
3. **실제 시간표/전우조 프리셋 적용**: 새 인원 등록 시 전우조(`메인 운영진`, `전우조1`, `전우조2`, `전원`) 및 시간대(`12:00 ~ 13:05`, `13:00 ~ 14:05`, `14:00 ~ 15:05`, `15:00 ~ 16:05`, `16:00 ~ 17:05`, `17:30 ~ 18:00`) 퀵 칩 지원.
4. **표/시간표 텍스트 자동 분류 및 관리자 검증 모달**: 관리자가 표 데이터를 붙여넣으면 자동 파싱 후 미리보기 테이블에서 검증을 거쳐 일괄 등록하는 `BatchImportModal` 구현.
5. **시간대 & 전우조별 컴팩트 가로 인라인 레이아웃**: 가로 공간을 최대한 활용하여 불필요한 세로 줄바꿈을 제거한 인라인 배치.
6. **동명이인 자동 통합 처리**: 스케줄 표에서 동일한 이름은 1명의 고유 멤버로 생성하고 스케줄 블록에 연결.
7. **색상 현황판 4열 고정 반응형 그리드**: 스마트폰/PC 어디서나 4열 고정 컴팩트 직사각형으로 25명 이상의 인원이 한 화면에 쏙 들어오도록 최적화.
8. **관리자 웹 알림 & 9분 초과 알림 (Notification API)**: 사용자의 자리비움/복귀 상태 전환 알림 및 9분(540초) 초과 시 경고 알림 발송.
9. **관리자 본인 상태 제어 & 사용자 화면 관리자 연락처**: 관리자 본인의 출석/자리비움 상단 제어 바 추가 및 사용자 화면 상단에 `[📞 관리자 연락처]` 원터치 확인 모달 연동.
10. **결석 처리 버튼 소형화**: 출석 상태인 멤버의 상세 관리 창에서 오클릭 방지를 위해 '결석으로 변경' 버튼을 미니 서브 버튼으로 축소.

## [1.2.0] - 2026-08-24

### 추가 및 개선 (Added & Enhanced)
1. **출석 1단계 강제 선결 조건 적용**:
   - 미출석(결석) 상태에서는 화장실, 흡연, 기타 자리비움 버튼이 비활성화되며, 출석 체크를 먼저 해야만 자리비움 기능을 사용할 수 있도록 강제
2. **인원 삭제 기능 안정화**:
   - 브라우저 기본 대화상자 대신 인앱 커스텀 확인 모달을 통해 인원을 안전하고 즉각적으로 삭제
3. **고대비(High Contrast) & 가독성 강화 디자인**:
   - 뚜렷한 보더(진한 테두리), 선명한 폰트 굵기(800/900), 직관적인 상태별 색상(출석: 에메랄드, 미출석: 차분한 슬레이트, 화장실: 스카이블루, 흡연: 오렌지, 기타: 바이올렛)으로 모바일 가독성 극대화
4. **최근 로그인 기록 자동 보관 & 원클릭 복원**:
   - 웹사이트를 나갔다 오더라도 최근 접속 룸 코드와 역할(관리자/사용자), 이름이 자동 보관되어 `[불러오기]` 버튼으로 원클릭 재입장 지원
5. **자리비움 상태 중복 전환 방지 & 알림**:
   - 화장실 중 복귀하지 않고 흡연/기타를 누를 때 무단 전환을 차단하고 "현재 [화장실] 이용 중입니다. 먼저 [복귀 (OFF)] 처리를 해주세요" 경고 및 차단 적용
6. **멋쟁이사자처럼 18명 부스 시간표 & 전우조 프리셋 일괄 등록**:
   - 시간대별(12시~1시, 1시~2시, 2시~3시, 3시~4시, 4시~5시, 5시반~6시), 메인 운영진, 전우조1, 전우조2가 매핑된 18명(26개 타임 배정) 시간표를 원클릭 일괄 등록 지원
7. **관리자 18명 한눈에 보는 "색상 현황판 (기본 메인 뷰)" 및 4종 뷰 다형화**:
   - 관리자 기본 화면이 18명의 이름과 상태 배경색이 표시되는 미니멀 바둑판(그리드) 타일로 구성
   - 각 타일 클릭 시 상세 제어 모달 오픈
   - 상단 카테고리 탭(`[색상 현황판]`, `[전우조별]`, `[시간대별]`, `[상세 목록]`)을 통해 조별/시간대별 정리된 뷰 즉시 전환
